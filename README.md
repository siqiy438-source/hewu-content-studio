# 禾物女装 · 原口播与拍摄工作台

当前文案库按原机器转录分类保留1469条候选业务口播；从原1545条参考中移除76条无业务口播、背景音乐/歌词或图文条目。已结合全1542条原音轨机器证据复核纳入范围，并逐项对照54处差异。原音轨局部复查找回2条误识别口播，另恢复1条门店集体祝福；原始机器证据保留。机器识别仍可能有错字，不为无口播内容补写台词。

文案规则：只将原始口播机器转录中的“广州”（含繁体“廣州”）替换为“福州”，其余文字、数字、标点、空白不改；不补写开头、结尾、到店邀请、面积或品牌词。原发布文字亦仅作相同城市替换，无新增标签。替换前原稿可以展开对照。机器转录尚未逐篇听音校对。

文案使用只读展示与复制，旧的自由改写稿和浏览器草稿不再覆盖原口播。收藏仍留在当前设备。

拍摄动作与口播分开：素材清单说明场景、构图、动作、拍摄秒数和数量；成片顺序及人物台词由原口播连续片段构成，拼接后与本条口播逐字一致。动作和剪辑时间是新拍建议，不冒充原片镜头统计。旧素材勾选记录不套用到新清单。

手机入口包括文案、拍摄手册、参考画面、计划、收藏。新人手册可用 `?view=guide` 直达；抖音链接查找可用 `?view=lookup` 直达。完整作品链接/编号精确定位，分享消息可按原发布文字找候选，纯短链接暂不能自动展开。删除条目的旧链接会提示已移出文案库。

原片截图和参考片段来自同品牌账号，可点击原作品对照。网站现有1469条画面文字记录，覆盖当前全部保留条目；机器观察与直接看图样例分别标记。原始1545条资料已完成机器画面记录、导出及完整性技术校验，缺失项为零；这不代表逐篇听音或连续看完原片。全库纳入判别和画面取样审查已执行；未将机器处理或取样检查标作逐篇人工听音、连续观看或文字绝对准确。

网站使用静态HTML、CSS、JavaScript，不需要登录；未引入外部短链接解析代理、账户密钥或输入上传。完整原始资料保存在本地资料库，与网站筛选展示分开。

多套素材准备样例已核对原片取样：六套穿搭需8条素材，五套连衣裙需7条，五组挂衣需12条（5条整套、5条细节、1条人物口播、1条环境）。每组配独立原图；展示段没有现成口播时保留环境声或自选音乐，不补写台词。全库8339条新拍素材的编号、数量、时长、图片引用及原话拼接通过技术审计。

局部复查恢复的3条均保留来源说明。2条原ASR固定幻听另存补充识别原字，不使用音频问答生成的改写；1条十人门店祝福使用原机器稿。正文和成片台词仅对所选来源原字做城市替换，源哈希、编号、旁白与全部引用由离线审计核对。

素材勾选按具体拍法与录制时长识别，调整编号不会把旧记录误套到另一件衣服。原勾选数组保留；能确定对应的旧记录自动迁移，拍法变化无法确定对应的旧编号单独列出供核对。收藏与原口播不受影响。
